# Example Usage

- `Use $dashboard-widget-builder to build a DataTable for tests and results.`
- `Use $dashboard-widget-builder to create dashboard StatCards for total samples and pending tests.`
- `Use $dashboard-widget-builder to create an AlertCard for low inventory warnings.`
- `Use $dashboard-widget-builder to build a new page and keep the locked marine and teal science theme.`

Example output request:

- `Generate reusable Tailwind components for StatCard, ChartCard, and AlertCard with simple props.`
- `Generate a new inventory dashboard page using the same theme as the current NextGen LIMS dashboard and logo.`
