# dashboard-widget-builder

This skill creates reusable dashboard interface blocks for the LIMS product.

It helps the project grow without rebuilding the same cards, tables, and alerts for every new screen.

The preferred design language for this project is a locked science theme: deep marine, teal highlights, mint accents, bright backgrounds, and easy-to-read cards. Pinterest inspiration links and the source theme files are stored in `SKILL.md` so future dashboard screens follow the same direction.
