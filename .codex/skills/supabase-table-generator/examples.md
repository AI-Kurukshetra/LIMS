# Example Usage

- `Use $supabase-table-generator to create a results table linked to tests.`
- `Use $supabase-table-generator to create a reports table with a unique report number.`
- `Use $supabase-table-generator to create a client portal access table with foreign keys.`

Example output request:

- `Generate a Supabase migration for a tests table with sample_id, status, priority, and proper indexes.`
